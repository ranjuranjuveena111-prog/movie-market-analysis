# 🎬 Movie Market Analysis

## 📌 Project Overview
This project analyzes historical movie data to help **CineData Studios** identify the most profitable and highly rated movie genres for future investments.

Using Python and data analysis libraries, the notebook explores ratings, revenues, durations, and genre performance to generate business insights.

---

## 🎯 Objectives

- Analyze average ratings by genre
- Identify the highest-rated genre
- Visualize revenue distribution
- Create a "Hit" classification based on movie ratings
- Perform exploratory data analysis (EDA)
- Generate insights for business decision-making

---
